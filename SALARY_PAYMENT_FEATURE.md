# Функционал выплаты зарплаты

## Описание

Реализован полноценный функционал выплаты зарплаты сотрудникам с автоматической фиксацией выплат и предотвращением повторных выплат за один период.

## Backend

### Новые компоненты

1. **Миграция БД** (`20260307_create_salary_payments.up.sql`)
   - Создана таблица `salary_payments` для хранения информации о выплатах
   - Индексы для быстрого поиска по периодам и сотрудникам
   - Ограничение уникальности для предотвращения повторных выплат

2. **Модель** (`models/salary_payment.go`)
   - `SalaryPayment` - структура для хранения данных о выплате
   - Связи с пользователем, счетом, транзакцией

3. **Repository** (`repositories/salary_payment_repository.go`)
   - Методы для работы с выплатами
   - `CheckIfPaid()` - проверка наличия выплаты за период

4. **UseCase** (`usecases/salary_usecase.go`)
   - `PaySalary()` - метод для выплаты зарплаты:
     * Проверка повторных выплат
     * Создание расходной транзакции
     * Пометка авансов как применённых
     * Фиксация выплаты в БД

5. **Handler** (`handlers/salary_handler.go`)
   - `PaySalary()` - endpoint для выплаты зарплаты
   - Валидация входных данных
   - Обработка ошибок (недостаточно средств, повторная выплата)

6. **Route** (`handlers/router.go`)
   - `POST /finance/salary/pay` - новый endpoint для выплаты

## Frontend

### Новые компоненты

1. **API Client** (`packages/api-client/src/hooks/useSalary.ts`)
   - `usePaySalary()` - hook для выплаты зарплаты
   - Типы: `PaySalaryRequest`, `SalaryPayment`

2. **UI компоненты**
   
   **PaySalaryModal** (`PaySalaryModal.tsx`)
   - Модальное окно выбора счета для выплаты
   - Отображение суммы к выплате с вычетом авансов
   - Проверка достаточности средств на счете
   
   **Salary** (`Salary.tsx`)
   - Кнопка "💰 Выплатить" для каждого сотрудника
   - Интеграция с модальным окном
   - Disabled для сотрудников с нулевой суммой к выплате

3. **Hook** (`hooks/useSalary.ts`)
   - `handleOpenPaymentModal()` - открытие модального окна
   - `handleConfirmPayment()` - подтверждение выплаты
   - Автообновление данных после выплаты

4. **Стили** (`styled.ts`)
   - Стили для модального окна
   - Кнопка выплаты с зеленым акцентом
   - Адаптивная верстка

## Процесс выплаты

1. Пользователь нажимает "💰 Выплатить" для сотрудника
2. Открывается модальное окно с:
   - Информацией о сотруднике
   - Периодом расчета
   - Начисленной суммой
   - Авансами к вычету
   - Итоговой суммой к выплате
   - Выбором счета для списания
3. При выборе счета проверяется достаточность средств
4. После подтверждения:
   - Создается расходная транзакция
   - Авансы помечаются как применённые
   - Создается запись о выплате в `salary_payments`
   - Обновляется баланс счета
5. Отчет о зарплате обновляется автоматически

## Защита от повторных выплат

- Уникальный индекс в БД по `(establishment_id, user_id, period_start, period_end)`
- Проверка `CheckIfPaid()` перед созданием выплаты
- HTTP 409 Conflict при попытке повторной выплаты

## API Endpoint

```
POST /api/v1/finance/salary/pay
```

**Request:**
```json
{
  "user_id": "uuid",
  "account_id": "uuid",
  "period_start": "2026-03-01T00:00:00Z",
  "period_end": "2026-03-31T23:59:59Z",
  "notes": "Зарплата за март 2026" // optional
}
```

**Response (201):**
```json
{
  "data": {
    "id": "uuid",
    "establishment_id": "uuid",
    "user_id": "uuid",
    "period_start": "2026-03-01T00:00:00Z",
    "period_end": "2026-03-31T23:59:59Z",
    "total_salary": 50000.00,
    "advances_deducted": 10000.00,
    "amount_paid": 40000.00,
    "account_id": "uuid",
    "transaction_id": "uuid",
    "payment_date": "2026-03-07T12:00:00Z",
    "paid_by": "uuid",
    "created_at": "2026-03-07T12:00:00Z",
    "updated_at": "2026-03-07T12:00:00Z"
  }
}
```

**Errors:**
- `400` - Недостаточно средств на счете
- `409` - Зарплата уже выплачена за этот период
- `500` - Внутренняя ошибка сервера

## Тестирование

Для тестирования функционала:

1. Запустите миграции:
```bash
cd backend
make migrate-up
```

2. Убедитесь, что есть:
   - Активные сотрудники
   - Смены за период
   - Счета с достаточным балансом

3. Откройте страницу `/salary` в admin-panel
4. Выберите период
5. Нажмите "Выплатить" для сотрудника
6. Выберите счет и подтвердите выплату
